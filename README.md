# صفحة تهنئة عيد ميلاد أبونا دميان 🎂

صفحة ويب تفاعلية حديثة وخفيفة (Single Page) برابط واحد و QR Code واحد، تتيح لشعب الكنيسة والمحبين كتابة تهنئة وكلمات محبة بمناسبة عيد ميلاد قدس أبونا دميان، مع حفظ جميع الرسائل تلقائياً في Google Sheets.

## المميزات:
- 📱 متوافقة 100% مع شاشات الموبايل (Mobile-First).
- ✍️ فورم بسيط: الاسم (اختياري) + نص التهنئة.
- 📊 حفظ مباشر في Google Sheets عبر Google Apps Script بدون أي تكلفة أو سيرفرات.
- 🎉 احتفالية مبهجة بمؤثرات الـ Confetti فور إرسال التهنئة.
- 📜 لوحة تهاني تعرض الرسائل بأناقة وتحديث فوري.
- 🖨️ توليد QR Code وتحميله كبوستر/كارت جاهز للطباعة والتعليق في الكنيسة.
- 💬 زر مشاركة سريع على واتساب ونسخ الرابط بضغطة زر.

## طريقة التشغيل:
راجع ملف [GUIDE.md](GUIDE.md) للتفاصيل الكاملة خطوة بخطوة.
